# Pirate Ships Landing Page — Руководство для AI-агентов

## Обзор проекта

Это статический лендинг для игры **Pirate Ships** (PvP-игра о строительстве кораблей и морских битвах). Сайт полностью на русском языке и представляет собой одностраничное приложение с семью основными секциями:

1. **Navigation** — фиксированная шапка с логотипом и меню.
2. **Hero** — полноэкранный баннер с Key Art, мерцающими звёздами и CTA-кнопкой.
3. **About** — текстовое описание игры.
4. **Features** — три карточки с особенностями игры.
5. **Screenshots** — горизонтальная карусель скриншотов с drag-to-scroll.
6. **Closing CTA** — финальный призыв к действию.
7. **Footer** — ссылки и копирайт.

## Технологический стек

- **HTML5** — семантическая разметка, русский язык контента (`lang="ru"`).
- **CSS3** — кастомные свойства в `:root`, анимации (`@keyframes`), flexbox, grid, медиа-запросы для адаптивности.
- **Vanilla JavaScript** — весь интерактив (мобильное меню, карусель, lightbox, свайпы) находится в конце `index.html` внутри `<script>`.
- **Внешние зависимости** — только шрифт **Lora** с Google Fonts.
- **Нет сборщиков, нет пакетных менеджеров** — проект не использует `package.json`, `pyproject.toml`, `Cargo.toml` или аналогичные конфигурации.

## Архитектура и организация кода

- **Монолитная структура**: весь HTML и JS содержится в одном файле `index.html`, а все стили — в `style.css`.
- **CSS-переменные** в `:root` задают единую цветовую схему и типографику:
  - `--color-bg: #0a0e17`
  - `--color-accent: #c9a227`
  - `--font-heading: 'Lora', serif`
- **Комментарии в коде** на русском языке разделяют секции и указывают, что можно редактировать.
- **Интерактивные компоненты** реализованы без сторонних библиотек:
  - Мобильное меню (бургер).
  - Карусель скриншотов со стрелками, drag-to-scroll и touch-свайпами.
  - Lightbox для полноэкранного просмотра скриншотов с клавиатурной навигацией (Escape, стрелки).

## Адаптивность

Медиа-запросы в `style.css` обеспечивают адаптацию под три диапазона:

- **Десктоп** — полная версия.
- **Планшеты (`max-width: 1024px`)** — сетка фичей из 2 колонок, увеличенные скриншоты.
- **Мобильные (`max-width: 768px` и `max-width: 480px`)** — одноколоночный layout, скрытые декоративные звёзды, упрощённая навигация, скрытые стрелки карусели.

## Соглашения по разработке

- **Язык комментариев** — русский. Все пояснения и разделители секций написаны на русском.
- **Маркеры для редактирования** — в HTML используется комментарий `<!-- ЗАМЕНИТЬ: ... -->`, чтобы указать кастомизируемый контент (тексты, ссылки, пути к изображениям).
- **Безопасность** — проект чисто клиентский, нет серверной логики, API-запросов или обработки пользовательских данных. Единственное внешнее подключение — Google Fonts через HTTPS.

## Сборка и деплой

- **Сборка не требуется** — проект состоит из статических файлов.
- **Локальный запуск** — достаточно открыть `index.html` в браузере или запустить простой HTTP-сервер (например, `python -m http.server` или `npx serve`).
- **Деплой** — копирование файлов `index.html`, `style.css` и папки `images/` на любой статический хостинг (GitHub Pages, Netlify, Vercel, S3 и т.д.).

## Тестирование

- **Автоматизированных тестов нет**.
- **Ручное тестирование** рекомендуется проводить в следующих сценариях:
  1. Проверка адаптивности в DevTools (ширины 1920px, 1024px, 768px, 390px).
  2. Проверка карусели: drag мышью, свайп на тач-устройстве, клик по скриншоту для открытия lightbox.
  3. Проверка мобильного меню: открытие/закрытие бургером.
  4. Проверка кросс-браузерности: Chrome, Firefox, Safari, Edge (последние версии).

## Чек-лист при внесении изменений

При редактировании лендинга следуй этому порядку:

1. **Тексты и ссылки** — ищи комментарии `<!-- ЗАМЕНИТЬ: ... -->` в `index.html`.
2. **Цвета и шрифты** — меняй CSS-переменные в `:root` в начале `style.css`.
3. **Изображения** — добавляй новые файлы в `images/` и обновляй `src` в HTML/CSS. Соблюдай регистр имён файлов (например, `Brush_2.png` с заглавной буквы).
4. **Скриншоты** — добавляй/удаляй блоки `.screenshot-item` в секции Screenshots. Индексы (`data-index`) должны идти последовательно от 0.
5. **Стили для новых элементов** — добавляй в соответствующую секцию `style.css`, сохраняя существующий порядок и форматирование.
